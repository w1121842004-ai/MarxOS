# MarxOS 固定评测问题集

这个文件用于每次修改检索、metadata、prompt 或 reranker 后做回归检查。建议每轮至少记录：问题、命中来源、页码是否可信、回答是否只基于材料、是否出现内部调试字段。

## 评测维度

| 维度 | 检查点 |
| --- | --- |
| 篇目定位 | 能否回答作品在哪一卷、从哪一页开始，且不编造页码 |
| 引文查找 | 能否只输出出处，不展开理论分析 |
| 概念解释 | 是否先定义，再说明理论位置，并附简短出处 |
| 理论分析 | 是否基于原著材料展开，而不是空泛口号 |
| 检索失败 | 不能确认时是否明确说明不确定 |

## 基准问题

### 1. 篇目定位

```text
《反杜林论》收录在哪一卷？
```

期望检查：

- 优先命中篇目映射或目录信息。
- 回答应包含卷号。
- 如果页码不确定，应说明页码需要复核。

```text
《自然辩证法》从哪一页开始？
```

期望检查：

- 回答应给出卷号和起始页。
- 不应只输出相似正文片段。

### 2. 引文查找

```text
“劳动首先是人和自然之间的过程”这句话出自哪里？
```

期望检查：

- 只输出出处或候选出处。
- 不应长篇解释劳动过程理论。
- 页码必须来自 metadata；如果只有 PDF 页码，要标明 PDF 页。

```text
“哲学家们只是用不同的方式解释世界，问题在于改变世界”出自哪一页？
```

期望检查：

- 能定位到《关于费尔巴哈的提纲》相关来源。
- 如果页码不稳定，应说明未能确认具体印刷页码。

### 3. 概念解释

```text
什么是剩余价值？
```

期望检查：

- 先给出简明定义。
- 再说明它在政治经济学中的理论位置。
- 至少附一个检索到的出处。

```text
什么是异化劳动？
```

期望检查：

- 不应只做现代口语解释。
- 应关联劳动、对象化、私有制等理论线索。

### 4. 理论分析

```text
如何用马克思主义分析平台经济中的劳动关系？
```

期望检查：

- 应从生产关系、资本逻辑、劳动过程或剩余价值角度分析。
- 能区分原著依据和理论延伸。

```text
为什么马克思说资本不是物，而是一种社会关系？
```

期望检查：

- 应解释资本的社会关系性质。
- 回答应有原著依据，不只给结论。

### 5. 检索失败与不确定性

```text
《一个不存在的马克思著作标题》收录在哪一卷？
```

期望检查：

- 应明确说未能确认。
- 不应硬编卷号、页码或出处。

```text
请给出“这是一句随便编造的引文”的准确页码。
```

期望检查：

- 应拒绝编造准确页码。
- 可以给出“未检索到可靠出处”的说明。
