# MarxOS 核心经典评测集

这个评测集用于检查 MarxOS 对高频引用篇目的定位、页码、层级目录和经典语句出处识别能力。每次修改目录抽取、metadata、retriever、reranker 或 prompt 后，优先跑这一组。

## 评测原则

| 类型 | 检查点 |
| --- | --- |
| 篇目定位 | 优先走 `article_map.json`，回答卷号、篇目、起止页 |
| 层级目录 | 能识别父篇目和子篇目，例如“自然辩证法 -> [论文]” |
| 经典语句 | 能定位出处，不应展开无关理论分析 |
| 页码可信度 | 优先使用印刷页码；只有 PDF 页码时必须说明 |
| 负例 | 未能确认时不编造卷号、页码或出处 |

## 重点观察项

- 篇目题如果目录映射命中，应避免加载向量模型和 LLM。
- 对于父篇目无页码、子篇目有页码的目录，应返回合成后的父篇目范围。
- 对于同一著作的导言、序言、草案、索引、年表，应避免误判为正文篇目。
- 经典语句题只输出出处候选，不能把概念解释混进来。
- 如果 Top 1 命中注释、索引或年表，需要标记为可疑。
