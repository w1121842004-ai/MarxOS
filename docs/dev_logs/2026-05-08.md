# 4. Key Engineering Problems（核心工程问题）

---

## Problem 1：Python 3.13/3.14 与 PaddleOCR 不兼容

### 现象

出现：

```text
PaddleOCR 无法运行
DLL 初始化失败
```

---

### Root Cause（根因）

PaddlePaddle 当前：

```text
尚未完全适配 Python 3.13+
```

存在：

```text
ABI compatibility issue
```

---

### Solution（解决方案）

统一降级：

```text
Python 3.10
```

重新构建虚拟环境。

---

## Problem 2：numpy / opencv ABI 冲突

### 现象

报错：

```text
numpy.core.multiarray failed to import
```

---

### Root Cause

OpenCV 与 numpy 版本不兼容。

最新版：

```text
opencv-python
```

自动升级：

```text
numpy 2.x
```

导致：

```text
PaddleOCR ABI 崩溃
```

---

### Solution

固定：

```text
numpy==1.23.5
opencv-python==4.6.0.66
```

---

## Problem 3：OCR 文本质量低

### 现象

OCR 输出存在：

* 换行混乱
* 空格异常
* 句子断裂

导致：

```text
Embedding quality 降低
```

---

### Solution

增加：

```python
clean_text()
```

进行：

* 去换行
* 去空格
* 文本清洗

---

## Problem 4：Chunk Semantic Pollution

### 现象

```text
chunk_size=500
```

导致：

```text
多个理论主题混入同一 chunk
```

检索精度下降。

---

### Solution

升级 Chunk Strategy：

```python
chunk_size=300
chunk_overlap=50
```

并增加：

```python
separators=["。","？","！"]
```

实现：

```text
中文语义切块
```

---

## 为什么采用 OCR-RAG

原因：

```text
马克思主义原著大量为扫描PDF
无法直接文本检索
```

```text
必须引入 OCR Pipeline
```

原因：

```text
Academic RAG
需要本地高性能向量检索
```

FAISS：

* 轻量
* 本地化
* 适合原型系统

---

## 为什么采用 Metadata

原因：

```text
Academic AI 必须支持 Citation
```

即：

```text
页码级引用
```
